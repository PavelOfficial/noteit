# План реализации NoteIt (Высокий уровень)

## Обзор проекта

**NoteIt** - многопользовательское десктоп-стилевое веб-приложение для создания и управления документами в формате Markdown.

## Технологический стек

- **Backend**: Python 3.8+, Flask 3.0
- **База данных**: SQLite (разработка), PostgreSQL (production)
- **ORM**: Flask-SQLAlchemy 3.1
- **Аутентификация**: Flask-Login 0.6
- **Формы**: Flask-WTF, WTForms
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **UI Framework**: Bootstrap 5.3
- **Markdown**: Python-Markdown 3.5
- **Безопасность**: Bleach для санитизации HTML

## Архитектурные принципы

### 1. Модульность (Flask Blueprints)
- Разделение функциональности по модулям
- Независимая разработка и тестирование
- Легкое добавление новых функций

### 2. Безопасность
- Все эндпоинты с данными пользователя защищены `@login_required`
- Фильтрация всех запросов по `user_id`
- CSRF защита для всех форм
- Санитизация HTML контента

### 3. Масштабируемость
- Stateless архитектура
- Готовность к горизонтальному масштабированию
- Оптимизированные запросы к БД

## Модели данных

### User (Пользователь)
- Хранение учетных данных
- Хеширование паролей (Werkzeug PBKDF2)
- Связи с документами и папками

### Document (Документ)
- Заголовок и содержимое (Markdown)
- Кэшированный HTML для быстрого отображения
- Связь с пользователем и папкой
- Флаги: избранное, архив

### Folder (Папка)
- Иерархическая структура (parent_id)
- Связь с пользователем
- Описание папки

## Функциональные модули

### 1. Аутентификация (auth.py)
**Эндпоинты:**
- `GET/POST /auth/register` - Регистрация
- `GET/POST /auth/login` - Вход
- `GET /auth/logout` - Выход

**Функции:**
- Валидация данных регистрации
- Проверка уникальности username/email
- Хеширование паролей
- Управление сессиями

### 2. Документы (documents.py)
**Эндпоинты:**
- `GET /documents/` - Список документов (с фильтрацией и пагинацией)
- `GET/POST /documents/create` - Создание документа
- `GET /documents/<id>` - Просмотр документа
- `GET/POST /documents/<id>/edit` - Редактирование документа
- `POST /documents/<id>/delete` - Удаление документа
- `POST /documents/<id>/toggle-favorite` - Переключение избранного
- `GET/POST /documents/search` - Поиск документов

**Функции:**
- CRUD операции
- Конвертация Markdown → HTML
- Санитизация HTML (Bleach)
- Фильтрация (папка, избранное, архив)
- Поиск по заголовку и содержимому
- Пагинация

### 3. Папки (folders.py)
**Эндпоинты:**
- `GET /folders/` - Список папок
- `GET/POST /folders/create` - Создание папки
- `GET /folders/<id>` - Просмотр папки
- `GET/POST /folders/<id>/edit` - Редактирование папки
- `POST /folders/<id>/delete` - Удаление папки

**Функции:**
- CRUD операции
- Иерархическая структура (подпапки)
- Валидация при удалении (проверка на наличие заметок/подпапок)

### 4. Главные страницы (main.py)
**Эндпоинты:**
- `GET /` - Главная страница (редирект на dashboard для авторизованных)
- `GET /dashboard` - Панель управления

**Функции:**
- Статистика пользователя
- Последние документы
- Избранные документы
- Список папок

## Потоки данных

### Создание документа
```
Пользователь → Форма → Валидация → Конвертация Markdown → 
Санитизация HTML → Сохранение в БД → Редирект на просмотр
```

### Просмотр документа
```
Запрос → Проверка авторизации → Запрос к БД (фильтр по user_id) → 
Проверка существования → Рендеринг шаблона → Отображение HTML
```

## Безопасность

### Уровни защиты

1. **Аутентификация**
   - Flask-Login для управления сессиями
   - Хеширование паролей (PBKDF2)
   - Защита от перебора (можно добавить rate limiting)

2. **Авторизация**
   - `@login_required` на всех защищенных эндпоинтах
   - Фильтрация всех запросов по `current_user.id`
   - Защита от IDOR (Insecure Direct Object Reference)

3. **Валидация данных**
   - WTForms для валидации форм
   - Проверка типов и ограничений
   - Санитизация HTML (Bleach)

4. **CSRF защита**
   - Flask-WTF для всех форм
   - CSRF токены в каждой форме

5. **SQL Injection**
   - SQLAlchemy ORM (параметризованные запросы)
   - Нет прямых SQL запросов
