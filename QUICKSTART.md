# Быстрый старт NoteIt

## Установка и запуск

### Шаг 1: Установите Python

Если Python не установлен, скачайте его с [python.org](https://www.python.org/downloads/) (версия 3.8 или выше).

**Важно:** При установке отметьте опцию "Add Python to PATH".

### Шаг 2: Установите зависимости

Откройте терминал в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

### Шаг 3: Создайте файл .env

**Важно:** Приложение требует установки SECRET_KEY для безопасности. 

**Вариант 1: Автоматическое создание (рекомендуется)**
При использовании скриптов `run.bat` или `run.ps1` файл `.env` будет создан автоматически со случайным SECRET_KEY.

**Вариант 2: Ручное создание**
Создайте файл `.env` в корне проекта. Сгенерируйте случайный SECRET_KEY:

```bash
python -c "import secrets; print('SECRET_KEY=' + secrets.token_hex(32))"
```

Скопируйте сгенерированный ключ в файл `.env`:

```
FLASK_APP=app.py
FLASK_ENV=development
SECRET_KEY=ваш-сгенерированный-ключ-здесь
DATABASE_URL=sqlite:///noteit.db
```

Или скопируйте `.env.example` в `.env` и замените SECRET_KEY на сгенерированный ключ.

### Шаг 4: Запустите приложение

**Вариант 1: Через Python**
```bash
python app.py
```

**Вариант 2: Через скрипт (Windows)**
```bash
.\run.bat
```

или

```powershell
.\run.ps1
```

### Шаг 5: Откройте в браузере

После запуска откройте браузер и перейдите по адресу:

**http://localhost:5000**

## Первое использование

1. Зарегистрируйте новый аккаунт
2. Войдите в систему
3. Создайте свою первую заметку!

## Остановка сервера

Нажмите `Ctrl+C` в терминале, где запущен сервер.
