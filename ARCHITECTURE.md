# Архитектура NoteIt

## Обзор архитектуры

NoteIt построен на основе **модульной архитектуры** с использованием Flask Blueprints, что обеспечивает:
- Разделение ответственности (Separation of Concerns)
- Масштабируемость
- Легкость тестирования
- Переиспользование кода

## Компоненты системы

### 1. Слой представления (Presentation Layer)

#### Templates (Jinja2)
- **base.html**: Базовый шаблон с навигацией и общими элементами
- **Модульные шаблоны**: Каждый Blueprint имеет свои шаблоны
- **Наследование**: Все шаблоны наследуются от base.html

#### Static Files
- **CSS**: Кастомные стили для улучшения UX
- **JavaScript**: Клиентская логика (AJAX, валидация)

### 2. Слой бизнес-логики (Business Logic Layer)

#### Blueprints (Модули)
```
main.py    → Главные страницы, dashboard
auth.py    → Аутентификация (login, register, logout)
documents.py → CRUD документов, поиск, фильтрация
folders.py → CRUD папок, иерархия
```

**Принципы Blueprints:**
- Каждый Blueprint отвечает за свою область функциональности
- Независимая маршрутизация
- Изолированная обработка ошибок

### 3. Слой данных (Data Layer)

#### Models (SQLAlchemy ORM)
```python
User    → Пользователи системы
Document → Документы в формате Markdown
Folder  → Папки для организации заметок
```

**Связи:**
- User 1:N Document (один пользователь - много документов)
- User 1:N Folder (один пользователь - много папок)
- Folder 1:N Document (одна папка - много документов)
- Folder 1:N Folder (иерархия папок)

#### Database (SQLite)
- Легковесная БД для разработки
- Легко мигрировать на PostgreSQL для production
- Автоматическое создание схемы через SQLAlchemy

### 4. Слой безопасности (Security Layer)

#### Аутентификация
- **Flask-Login**: Управление сессиями пользователей
- **Werkzeug**: Хеширование паролей (PBKDF2)
- **Session Management**: Безопасные сессии с настройками cookies

#### Авторизация
- **@login_required**: Декоратор для защиты маршрутов
- **User Context**: Все запросы фильтруются по current_user.id
- **CSRF Protection**: Flask-WTF для защиты форм

#### Санитизация
- **Bleach**: Очистка HTML от потенциально опасных тегов
- **Whitelist**: Разрешенные теги и атрибуты для Markdown

## Потоки данных

### Создание документа
```
1. Пользователь → Форма (DocumentForm)
2. Форма → Валидация (WTForms)
3. Валидация → Blueprint (documents.create_document)
4. Blueprint → Проверка авторизации (@login_required)
5. Blueprint → Конвертация Markdown → HTML
6. Blueprint → Санитизация HTML (Bleach)
7. Blueprint → Сохранение в БД (SQLAlchemy)
8. Blueprint → Редирект на просмотр
```

### Просмотр документа
```
1. Пользователь → Запрос /documents/<id>
2. Blueprint → Проверка авторизации
3. Blueprint → Запрос к БД (фильтр по user_id)
4. Blueprint → Проверка существования (first_or_404)
5. Blueprint → Рендеринг шаблона
6. Шаблон → Отображение HTML (из content_html)
```

## Паттерны проектирования

### 1. Factory Pattern
```python
def create_app(config_class=Config):
    # Создание и настройка приложения
    app = Flask(__name__)
    # ...
    return app
```

### 2. Blueprint Pattern
- Модульная организация маршрутов
- Изоляция функциональности

### 3. Repository Pattern (через SQLAlchemy)
- Абстракция доступа к данным
- Единая точка доступа к БД

### 4. Decorator Pattern
- `@login_required` для защиты маршрутов
- `@app.route` для маршрутизации

## Масштабируемость

### Горизонтальное масштабирование
- Stateless приложение (сессии в cookies)
- Можно запускать несколько инстансов
- Требуется общая БД (PostgreSQL для production)

### Вертикальное масштабирование
- Оптимизация запросов к БД (индексы)
- Кэширование (Flask-Caching для будущего)
- Пагинация для больших списков

## Производительность

### Оптимизации
1. **Кэширование HTML**: `content_html` хранится в БД
2. **Индексы БД**: На `user_id`, `folder_id`, `created_at`
3. **Пагинация**: Ограничение количества записей на странице
4. **Lazy Loading**: SQLAlchemy lazy='dynamic' для связей

### Будущие улучшения
- Redis для кэширования
- CDN для статических файлов
- Асинхронные задачи (Celery)
- Full-text search (FTS) для SQLite/PostgreSQL

## Безопасность

### Уровни защиты

1. **Аутентификация**
   - Хеширование паролей (PBKDF2)
   - Безопасные сессии
   - Защита от перебора паролей (можно добавить rate limiting)

2. **Авторизация**
   - Проверка прав доступа на каждом эндпоинте
   - Фильтрация по user_id во всех запросах
   - Защита от IDOR (Insecure Direct Object Reference)

3. **Валидация входных данных**
   - WTForms для валидации форм
   - Санитизация HTML (Bleach)
   - Защита от XSS

4. **CSRF защита**
   - Flask-WTF для всех форм
   - CSRF токены

5. **SQL Injection**
   - SQLAlchemy ORM (параметризованные запросы)
   - Нет прямых SQL запросов

- Изоляция тестов (каждый тест независим)

## Развертывание

### Development
- SQLite для простоты
- Debug режим включен
- Автоперезагрузка при изменениях

### Production
- PostgreSQL для надежности
- Gunicorn/uWSGI как WSGI сервер
- Nginx как reverse proxy
- HTTPS обязателен
- Логирование и мониторинг
- Резервное копирование БД

## Расширяемость

### Легко добавить:
- Новые Blueprints для новых функций
- Новые модели данных
- API endpoints (Flask-RESTful)
- WebSocket поддержка (Flask-SocketIO)
- Фоновые задачи (Celery)
- Миграции БД (Flask-Migrate)

### Пример добавления нового модуля:
```python
# blueprints/tags.py
tags_bp = Blueprint('tags', __name__)

@tags_bp.route('/')
@login_required
def list_tags():
    # ...
```
