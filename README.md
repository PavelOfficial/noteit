# NoteIt

**NoteIt** — современное многопользовательское веб-приложение для создания, редактирования и организации заметок в формате Markdown. Приложение обеспечивает полную изоляцию данных между пользователями и предоставляет удобный интерфейс для управления личными документами.

## 🎯 Краткий обзор

NoteIt — это полнофункциональное веб-приложение для работы с заметками, построенное на Flask. Приложение позволяет пользователям:

- **Создавать и редактировать документы** в формате Markdown с автоматическим преобразованием в HTML
- **Организовывать заметки** в иерархическую структуру папок
- **Быстро находить информацию** с помощью полнотекстового поиска
- **Управлять избранными** и архивировать документы
- **Работать безопасно** благодаря многопользовательской архитектуре с полной изоляцией данных

Приложение использует модульную архитектуру на основе Flask Blueprints, что обеспечивает масштабируемость, легкость тестирования и поддержки кода.

## ✨ Features

### Основные возможности

- **🔐 Аутентификация и авторизация**
  - Регистрация новых пользователей с валидацией данных
  - Безопасный вход в систему с управлением сессиями
  - Защита паролей с использованием PBKDF2 хеширования
  - Автоматическая нормализация email адресов

- **📝 Управление документами**
  - Создание, редактирование и удаление документов
  - Поддержка Markdown синтаксиса с автоматическим преобразованием в HTML
  - Кэширование HTML для быстрого отображения
  - Санитизация HTML для защиты от XSS атак
  - Пагинация списка документов (20 на страницу)

- **📁 Организация в папках**
  - Создание иерархической структуры папок
  - Привязка документов к папкам
  - Вложенные папки (подпапки)
  - Валидация при удалении (проверка наличия документов и подпапок)

- **🔍 Поиск и фильтрация**
  - Полнотекстовый поиск по заголовкам и содержимому документов
  - Фильтрация по папкам
  - Фильтрация избранных документов
  - Фильтрация архивных документов

- **⭐ Дополнительные функции**
  - Отметка документов как избранных
  - Архивирование документов
  - Панель управления (dashboard) с последними документами и статистикой
  - Адаптивный дизайн на Bootstrap 5

### Безопасность

- CSRF защита для всех форм (Flask-WTF)
- Хеширование паролей (Werkzeug PBKDF2)
- Санитизация HTML контента (Bleach)
- Изоляция данных пользователей (фильтрация по user_id)
- Валидация email адресов
- Защита от SQL инъекций (SQLAlchemy ORM)

## 🚀 Getting Started

Этот раздел содержит пошаговые инструкции по настройке окружения разработки, установке зависимостей, инициализации базы данных и запуску приложения.

### Предварительные требования

Перед началом работы убедитесь, что у вас установлены:

- **Python 3.8 или выше** ([скачать](https://www.python.org/downloads/))
- **pip** (обычно устанавливается вместе с Python)
- **Git** (опционально, для клонирования репозитория)

Проверьте версию Python:
```bash
python --version
# или
python3 --version
```

### Шаг 1: Получение кода проекта

#### Вариант A: Клонирование репозитория
```bash
git clone <repository-url>
cd NoteIt-Project
```

#### Вариант B: Работа с существующей директорией
Если проект уже находится на вашем компьютере, перейдите в директорию проекта:
```bash
cd path/to/NoteIt-Project
```

### Шаг 2: Создание виртуального окружения

Рекомендуется использовать виртуальное окружение для изоляции зависимостей проекта.

#### Windows
```bash
python -m venv venv
venv\Scripts\activate
```

#### Linux / macOS
```bash
python3 -m venv venv
source venv/bin/activate
```

После активации виртуального окружения в начале строки терминала появится префикс `(venv)`.

**Примечание:** Для деактивации виртуального окружения выполните команду `deactivate`.

### Шаг 3: Установка зависимостей

Установите все необходимые пакеты из файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

Это установит все зависимости, включая:
- Flask и связанные расширения
- SQLAlchemy для работы с БД
- Markdown и Bleach для обработки контента
- pytest для тестирования

Проверьте установку:
```bash
pip list
```

### Шаг 4: Настройка конфигурации

Приложение требует настройки переменных окружения, особенно `SECRET_KEY` для безопасности.

#### Создание файла .env

Создайте файл `.env` в корне проекта. Есть несколько способов:

**Способ 1: Автоматическое создание (Windows)**

Используйте встроенные скрипты:
```bash
.\run.bat
# или
.\run.ps1
```

Эти скрипты автоматически создадут файл `.env` со случайным `SECRET_KEY`.

**Способ 2: Ручное создание**

1. Сгенерируйте случайный `SECRET_KEY`:
```bash
python -c "import secrets; print('SECRET_KEY=' + secrets.token_hex(32))"
```

2. Создайте файл `.env` в корне проекта со следующим содержимым:
```env
FLASK_APP=app.py
FLASK_ENV=development
SECRET_KEY=ваш-сгенерированный-ключ-здесь
DATABASE_URL=sqlite:///noteit.db
```

**Важно:** 
- Никогда не коммитьте файл `.env` в систему контроля версий
- Используйте разные `SECRET_KEY` для development и production окружений
- Для production используйте более сложные методы генерации ключей

### Шаг 5: Инициализация базы данных

База данных SQLite создается автоматически при первом запуске приложения. Таблицы создаются через SQLAlchemy методом `db.create_all()`.

**Ручная инициализация (опционально):**

Если вы хотите явно инициализировать БД, выполните:
```bash
python -c "from app import create_app; from extensions import db; app = create_app(); app.app_context().push(); db.create_all(); print('База данных инициализирована')"
```

База данных будет создана в директории `instance/noteit.db`.

**Примечание:** 
- Для разработки используется SQLite
- Для production рекомендуется PostgreSQL
- Для миграции на PostgreSQL измените `DATABASE_URL` в `.env`

### Шаг 6: Запуск приложения

Выберите один из способов запуска:

#### Способ 1: Прямой запуск через Python
```bash
python app.py
```

Приложение запустится на `http://localhost:5000`

#### Способ 2: Использование Flask CLI
```bash
flask run
```

Или с указанием хоста и порта:
```bash
flask run --host=0.0.0.0 --port=5000
```

#### Способ 3: Использование скриптов (Windows)
```bash
.\run.bat
# или
.\run.ps1
```

Эти скрипты автоматически:
- Проверят наличие Python
- Создадут виртуальное окружение (если нужно)
- Установят зависимости
- Создадут `.env` файл (если нужно)
- Запустят приложение

### Шаг 7: Проверка работы приложения

1. Откройте браузер и перейдите по адресу: **http://localhost:5000**

2. Вы должны увидеть главную страницу приложения

3. Попробуйте зарегистрировать нового пользователя:
   - Перейдите на `/auth/register`
   - Заполните форму регистрации
   - После успешной регистрации вы будете перенаправлены на страницу входа

4. Войдите в систему и проверьте доступ к dashboard

### Устранение проблем

#### Проблема: "SECRET_KEY не установлен"
**Решение:** Убедитесь, что файл `.env` существует и содержит `SECRET_KEY`. Проверьте, что файл находится в корне проекта.

#### Проблема: "ModuleNotFoundError"
**Решение:** Убедитесь, что виртуальное окружение активировано и все зависимости установлены:
```bash
pip install -r requirements.txt
```

#### Проблема: "Port 5000 already in use"
**Решение:** Используйте другой порт:
```bash
flask run --port=5001
```

Или остановите процесс, использующий порт 5000.

#### Проблема: База данных не создается
**Решение:** Убедитесь, что директория `instance/` существует и доступна для записи. Приложение создаст её автоматически при первом запуске.

## 📖 Использование

### Регистрация и вход

1. **Регистрация нового аккаунта:**
   - Перейдите на `/auth/register`
   - Заполните форму: имя пользователя, email, пароль
   - После успешной регистрации вы будете перенаправлены на страницу входа

2. **Вход в систему:**
   - Перейдите на `/auth/login`
   - Введите имя пользователя и пароль
   - При успешном входе вы попадете на dashboard

### Работа с документами

1. **Создание документа:**
   - Перейдите в раздел "Документы" → "Новый документ"
   - Введите заголовок и содержимое в формате Markdown
   - Опционально выберите папку для организации
   - Сохраните документ

2. **Редактирование документа:**
   - Откройте документ для просмотра
   - Нажмите "Редактировать"
   - Внесите изменения и сохраните

3. **Управление документами:**
   - Отметить как избранное: кнопка "⭐" в списке документов
   - Архивировать: установите флаг "Архив" при редактировании
   - Удалить: кнопка "Удалить" в интерфейсе редактирования

### Работа с папками

1. **Создание папки:**
   - Перейдите в раздел "Папки" → "Новая папка"
   - Введите название и описание (опционально)
   - Выберите родительскую папку для создания иерархии

2. **Организация документов:**
   - При создании/редактировании документа выберите папку
   - Документы можно перемещать между папками

### Поиск

- Используйте поиск в навигационной панели
- Введите запрос для поиска по заголовкам и содержимому
- Результаты отображаются с подсветкой найденных фрагментов

### Markdown синтаксис

Приложение поддерживает стандартный синтаксис Markdown:

- **Заголовки:** `# H1`, `## H2`, `### H3`
- **Жирный текст:** `**текст**` или `__текст__`
- **Курсив:** `*текст*` или `_текст_`
- **Списки:** `- элемент` или `1. элемент`
- **Ссылки:** `[текст](url)`
- **Код:** `` `код` `` или блоки кода с тройными backticks
- **Цитаты:** `> цитата`
- И многое другое

## 🔒 Безопасность

### Рекомендации для production

1. **SECRET_KEY:**
   - Используйте сильный случайный ключ (минимум 32 символа)
   - Храните ключ в переменных окружения, не в коде
   - Используйте разные ключи для разных окружений

2. **HTTPS:**
   - Обязательно используйте HTTPS в production
   - Установите в `config.py`:
   ```python
   SESSION_COOKIE_SECURE = True
   ```

3. **База данных:**
   - Мигрируйте на PostgreSQL для production
   - Настройте регулярное резервное копирование
   - Используйте connection pooling

4. **Дополнительные меры:**
   - Настройте rate limiting (Flask-Limiter)
   - Включите логирование для мониторинга
   - Регулярно обновляйте зависимости
   - Используйте WAF (Web Application Firewall)
